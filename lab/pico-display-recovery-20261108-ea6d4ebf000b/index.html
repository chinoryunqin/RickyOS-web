小纸 Pico 显示恢复

用于屏幕停在旧画面、电脑仍能识别设备的小纸 Pico（RDP-G01-W）。刷入后可通过 USB 读取诊断，再手动请求一次清屏。

正在检查恢复包。

1. 连接并检查设备

用电脑上的 Chrome 或 Edge 打开页面。用 USB 数据线连接，关闭其他占用串口的程序。设备需能进入 ESP32 下载模式。

2. 刷入恢复固件

恢复固件会覆盖当前启动应用。写入期间请保持 USB 连接和电脑唤醒。

0%

3. 读取 USB 诊断

恢复固件启动后重新连接串口，先读取诊断。检查通过后可以尝试一次清屏，记下屏幕变化并把日志交给维护者。

诊断结束后，可关闭诊断串口，用平时的刷机方式装回原固件。
