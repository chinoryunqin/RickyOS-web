小纸 Pico 显示恢复

用于屏幕停在旧画面、电脑仍能识别设备的小纸 Pico（RDP-G01-W）。刷入后网页会读取诊断并显示故障位置。板级检查通过时，可在同一页尝试一次清屏。

正在检查恢复包。

1. 连接并检查设备

用电脑上的 Chrome 或 Edge 打开页面。用 USB 数据线连接，关闭其他占用串口的程序。设备需能进入 ESP32 下载模式。

2. 刷入恢复固件

恢复固件会覆盖当前启动应用。写入期间请保持 USB 连接和电脑唤醒。

0%

3. 读取 USB 诊断

刷入并重启后自动读取诊断。如果串口没有自动接上，点「读取诊断（连接 USB）」。

清屏结束后，你看到什么？
